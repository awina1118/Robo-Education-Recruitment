# 内训方案：STM32 嵌入式入门——从点灯到让小车跑起来

## 1. 课程名称与主要内容

**课程名称**：STM32 嵌入式入门——从点灯到让小车跑起来

**为什么选这个方向**

- 协会的 AnyCar 巡线小车用的是 Arduino，大家入门很快，但 Arduino 把硬件细节都封装起来了。到了比赛和实际项目里（RoboMaster、电赛、智能车），主控几乎都是 STM32，很多同学会卡在“从 Arduino 到 STM32”这一步。
- STM32 的资料多、价格低（核心板十几元），协会已有的 AnyCar 底盘、L298N、电机、循迹传感器都可以直接复用。
- 课程最后用 STM32 替换 AnyCar 上的 Arduino，重新实现巡线，和协会已有的课程体系衔接。

**主要内容**：GPIO 输入输出、外部中断、定时器与 PWM、串口通信、ADC 采样，以及一个巡线小车综合项目。全程使用 ST 官方的 HAL 库和 CubeMX 图形化配置，降低寄存器门槛，但每一讲都会解释 HAL 函数背后对应的硬件原理。

## 2. 面向对象与所需基础

- **面向对象**：机协新成员（大一为主）、上过 AnyCar 内训、想参加机器人或电子类比赛的同学。
- **前置基础**：
  - 必需：C 语言基础（变量、`if`/`for`、函数）。没学过的同学可在开课前看一遍提供的 C 语言速查，或与《C 程序设计》课程同步学习。
  - 加分：用过 Arduino、知道什么是高低电平。
  - 不需要：数字电路、寄存器、汇编知识。

## 3. 学习目标

完成课程后，参与者能够：

1. 独立搭建 STM32 开发环境，新建工程、编译、烧录、调试。
2. 用 CubeMX 配置 GPIO、中断、定时器、串口、ADC，并说清楚每个外设是干什么的。
3. 看懂核心板原理图和芯片手册中的引脚定义，自己查资料解决“这个引脚能不能用”的问题。
4. 用 PWM + L298N 控制电机转速和方向，用 ADC 读取传感器。
5. 完成 STM32 版巡线小车，并具备继续学习 FreeRTOS、PID 控制等内容的基础。

## 5. 教学形式与实践环节

- **每讲 2 小时**：讲授约 40 分钟 + 跟做演示约 20 分钟 + 动手实践约 60 分钟。
- **“先跑起来，再讲原理”**：每讲先让大家用最少的步骤看到现象（灯亮了、电机转了），再回头讲寄存器和时序，避免一开始就被概念劝退。
- **两人一组**：一人操作一人查资料，每讲轮换。综合项目两人共用一台小车。
- **助教**：每 8--10 人配一名助教（往届学长学姐），负责现场排错。
- **课后任务**：每讲留一个小作业（10--30 分钟），下一讲开头用 5 分钟抽查。
- **资料**：每讲的幻灯片、示例工程、常见错误清单上传到协会 GitHub 仓库。

## 6. 课时安排

| 课时 | 主题 | 讲授内容 | 实践任务 |
| --- | --- | --- | --- |
| 1 | 认识 STM32 + GPIO 输出 | 单片机是什么；STM32 命名规则；开发环境；GPIO 推挽/开漏输出 | 安装 CubeIDE，新建工程，点亮板载 LED，实现流水灯 |
| 2 | GPIO 输入与外部中断 | 上拉/下拉输入；按键抖动与消抖；轮询 vs 中断；NVIC 优先级 | 按键控制 LED 亮灭；用 EXTI 中断实现同样功能并对比 |
| 3 | 定时器与 PWM | 时钟树；预分频与自动重装载；PWM 占空比；舵机控制原理 | 呼吸灯；用 PWM 控制舵机转到指定角度 |
| 4 | 串口通信 UART | 波特率、起始位、停止位；`printf` 重定向；中断接收 | 把变量打印到电脑上调试；电脑发命令控制 LED |
| 5 | ADC 与传感器 | 模拟量与数字量；分辨率与参考电压；多通道扫描 | 读电位器电压并通过串口显示；读四路循迹传感器 |
| 6 | 综合项目：巡线小车 | L298N 驱动（衔接纳新电路题）；巡线逻辑；简单的比例控制 | 用 STM32 替换 AnyCar 上的 Arduino，跑完测试赛道 |

课程总时长约 12 小时，建议每周一讲，6 周完成。第 6 讲结束后安排一次巡线计时赛，作为结课展示。

## 7. 可能遇到的问题与解决办法

| 问题 | 解决办法 |
| --- | --- |
| 学员基础差异大，有人觉得太快、有人觉得太慢 | 每讲的实践任务分“基础 / 进阶”两档；做完基础的同学继续挑战进阶，助教优先照顾卡住的同学 |
| 环境配置出错耗时（驱动、ST-Link 识别不到） | 开课前一周发安装文档和视频，组织一次线上答疑；现场准备装好环境的备用电脑 |
| 下载失败、芯片“锁死” | 常见原因整理成排错清单（BOOT0 跳线、SWD 被关闭、供电不足），并教会用 ST-Link Utility 擦除恢复 |
| 硬件损坏或数量不足 | 按 10% 冗余采购；接线前统一讲“先断电再接线”“电源正负极不能接反”；每次课后清点 |
| 学员只会照抄代码、不理解原理 | 每讲的作业要求改动示例代码实现新功能（如改变流水灯顺序），而不是原样复现 |
| 中途流失 | 每讲都有看得见的成果；第 6 讲有计时赛和小奖品；课程资料对未完成的同学持续开放 |
| HAL 库封装过深，学员不知道底层发生了什么 | 第 1、3 讲各安排一个“拆开 HAL 看寄存器”的环节，在调试器里观察寄存器变化 |
